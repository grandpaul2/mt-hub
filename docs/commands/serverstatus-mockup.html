A. One card, a row per server

The mod release card's shape with a small table inside. Compact, and the numbers line up for comparing the two servers.

B. A tile per server

Each server is its own tile with larger numbers; the left edge is green when it's up and grey when it's down. Side by side when there's room, stacked in the side chat.

C. With the last ten minutes drawn

Adds a small mspt graph (the dashed line is 50, where the server starts falling behind) and a memory bar. The tallest of the four, and the only one that shows a lag spike that has already passed.

D. Plain lines, no card

The quietest: one line per server and the names under it. Reads like a chat message that only you see.
