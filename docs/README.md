# Docs

| Doc | What it is |
|-----|------------|
| `style-guide.md` | How the hub looks and behaves. Agreed with Paul; it wins over the code. |
| `hub-backlog.md` | Specs for built and planned work, and the **Later** list where every deferred idea goes. |
| `discord-replacement.md` | The original design: why the hub exists and what it had to replace. |
| `hub-dialog-conventions.md` | Research behind the dialog and menu rules in the style guide. |
| `voice/` | Voice chats: design (`rooms-design.md`), research, and `svc/` for Simple Voice Chat and Voice Link. |
| `stream/` | Screen sharing (`screen-share-spec.md`, built). |
| `topbar/`, `commands/` | Mockups. |

These were written while the hub was being designed, so they name our own setup. A path
starting `server/` (`server/relay/README.md`, `server/hub/README.md`, the modlists) is in
MacroTech's private ops repo: the runbooks for our relay, backups and game servers. Paths
like `server/chat.go` are short for `internal/server/chat.go` here.
